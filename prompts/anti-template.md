# Anti-template brief (prepend to any UI task)
Do NOT ship the stock AI-SaaS page: purple/indigo gradient hero, centered H1 + two buttons, row of 3 icon cards, logo cloud, 3-tier pricing, generic stock copy.
Instead: pick ONE distinct layout archetype (layout-archetypes T1-T17, different from the last 3 projects), a unique accent from the registry, a live product demo in the hero, real copy about the actual product.
Check: `npx impeccable detect <dir>` (no hooks), then taste-skill anti-slop checklist. If the owner explicitly asks for the standard template, the hub flag `design.templateOk=true` allows it.
